# FitAI - مربی هوشمند بدنسازی

یک وب‌اپلیکیشن حرفه‌ای، مدرن و فارسی برای مربی هوشمند بدنسازی با قابلیت PWA (Progressive Web App).

## 🚀 روش‌های استفاده روی موبایل

### روش ۱: نصب به عنوان PWA (توصیه می‌شود)

#### در اندروید (Chrome):
1. سایت را در مرورگر Chrome باز کنید
2. روی منوی سه‌نقطه (⋮) در بالا سمت راست بزنید
3. گزینه **"Add to Home screen"** یا **"نصب اپلیکیشن"** را انتخاب کنید
4. روی **"Install"** بزنید
5. آیکون FitAI به صفحه اصلی گوشی شما اضافه می‌شود

#### در آیفون (Safari):
1. سایت را در مرورگر Safari باز کنید
2. روی دکمه **Share** (مربع با فلش رو به بالا) در پایین صفحه بزنید
3. گزینه **"Add to Home Screen"** را انتخاب کنید
4. روی **"Add"** بزنید
5. آیکون FitAI به صفحه اصلی گوشی شما اضافه می‌شود

### روش ۲: استفاده از طریق مرورگر
- کافیست URL سایت را در مرورگر موبایل باز کنید
- تمام قابلیت‌ها در دسترس هستند
- داده‌ها به صورت محلی ذخیره می‌شوند

### روش ۳: Deploy روی هاست شخصی

#### گزینه‌های رایگان:

**Vercel:**
```bash
npm install -g vercel
vercel
```

**Netlify:**
```bash
npm run build
# پوشه dist را در Netlify drag & drop کنید
```

**GitHub Pages:**
```bash
npm run build
# محتوای پوشه dist را در branch gh-pages قرار دهید
```

2. **پروفایل** - اطلاعات بدنی و اهداف
3. **ارزیابی بدنی** - اندازه‌گیری‌ها
4. **تصاویر بدن** - مقایسه ظاهری
5. **برنامه تمرینی** - برنامه هوشمند
6. **برنامه فشرده** - برای زمان محدود
7. **تقویم تمرین** - برنامه هفتگی
8. **ثبت غذا** - تغذیه روزانه
9. **بانک غذا** - 60+ ماده غذایی ایرانی
10. **تحلیل تغذیه** - تحلیل هوشمند
11. **مکمل‌ها** - پیشنهادات مکمل
12. **یادآورها** - Reminder و Alarm
13. **پیشرفت** - نمودارها و آمار

## 🛠️ توسعه محلی

```bash
# نصب وابستگی‌ها
npm install

# اجرای سرور توسعه
npm run dev

# Build برای تولید
npm run build

# پیش‌نمایش build
npm run preview
```

## 💾 ذخیره‌سازی داده‌ها

تمام داده‌ها به صورت محلی در `localStorage` مرورگر ذخیره می‌شوند:
- اطلاعات پروفایل
- برنامه تمرینی
- ثبت تغذیه
- تصاویر بدن
- یادآورها
- تاریخچه وزن و تمرینات
